# DowTheory_USDJPY EA — 設定・使用ガイド

## 概要

ダウ理論をベースにした USDJPY 専用の MT5 Expert Advisor です。
**M15チャート**で動作し、HH/HL・LH/LL によるトレンド判定から
押し目・戻り目エントリーとブレイクアウトエントリーを行います。

---

## インストール手順

1. `DowTheory_USDJPY.mq5` を MT5 の以下のフォルダにコピー
   ```
   (MT5インストール先)\MQL5\Experts\
   ```
2. MT5 の MetaEditor でコンパイル（F7）
3. USDJPY の M15 チャートに EA をドラッグ&ドロップ
4. 「自動売買を許可する」にチェック → OK

---

## ロジック解説

### 1. スウィングポイント検出

直近120バーの**確定済みバー**を走査し、局所的な高値・安値を検出します。

```
スウィングハイ: 左右 InpSwingLookback 本のバーより高い高値
スウィングロー: 左右 InpSwingLookback 本のバーより低い安値
```

### 2. ダウ理論によるトレンド判定

直近 `InpSwingCount` 個のスウィング高値・安値のシーケンスを判定:

| パターン | 判定 |
|---------|------|
| HH（高値切り上げ） + HL（安値切り上げ） | 上昇トレンド |
| LH（高値切り下げ） + LL（安値切り下げ） | 下降トレンド |
| どちらでもない | レンジ（エントリーなし） |

### 3. 上位足フィルター（H1）

M15 のトレンドと H1 のトレンドが**同方向**の場合のみエントリー。
逆張りや逆トレンドを避けます。

### 4. 出来高フィルター

直前バーのティックボリュームが過去 `InpVolPeriod` バーの平均×`InpVolMultiplier` 以上のときのみエントリー。
出来高の薄い時間帯（東京早朝、週明け）を除外します。

### 5-A. 押し目・戻り目エントリー

```
上昇トレンドの押し目買い:
  エントリーゾーン = 直近HH から (HH - 前回HL) × InpPullbackRatio (デフォルト61.8%) の水準 ± 8%
  SL              = 前回HL の少し下 (InpSLBuffer pips)
  TP              = エントリー + (エントリー - SL) × InpRRRatio

下降トレンドの戻り売り:
  エントリーゾーン = 直近LL から (前回LH - LL) × InpPullbackRatio の水準 ± 8%
  SL              = 前回LH の少し上
  TP              = エントリー - (SL - エントリー) × InpRRRatio
```

### 5-B. ブレイクアウトエントリー

```
上昇ブレイクアウト:
  条件: 直前確定バーの終値が直近スウィングハイ + InpBreakoutPips を上抜け
        かつ 同バーの始値は上抜け前
  SL:   直近スウィングローの少し下
  TP:   エントリー + (エントリー - SL) × RR

下降ブレイクアウト: 逆方向で同じ
```

### 6. トレーリングストップ

```
BUY:  利益が InpTrailingStart pips を超えたら
      SL を (現在BID - InpTrailingStep pips) に移動

SELL: 利益が InpTrailingStart pips を超えたら
      SL を (現在ASK + InpTrailingStep pips) に移動
```

## パラメーター一覧

### リスク管理

| パラメーター | デフォルト | 説明 |
|------------|-----------|------|
| InpRiskPercent | 1.0 | 1トレードあたりのリスク率（口座残高の%） |
| InpRRRatio | 2.0 | リスクリワード比（1:2） |
| InpMagicNumber | 20250101 | EA識別番号 |

### ダウ理論設定

| パラメーター | デフォルト | 説明 |
|------------|-----------|------|
| InpSwingLookback | 5 | スウィング判定の左右バー数 |
| InpSwingCount | 3 | トレンド確認に必要なスウィング数 |
| InpUseHigherTF | true | H1フィルター使用 |
| InpHigherTF | H1 | 上位足の時間足 |

### エントリー設定

| パラメーター | デフォルト | 説明 |
|------------|-----------|------|
| InpUsePullback | true | 押し目・戻り目エントリー |
| InpUseBreakout | true | ブレイクアウトエントリー |
| InpPullbackRatio | 0.618 | 押し目の深さ（0.382=浅い, 0.618=深い） |
| InpPBZoneBuffer | 0.08 | 押し目ゾーンの幅（スウィング幅の±8%） |
| InpBreakoutPips | 3.0 | ブレイク確認バッファ（pips） |
| InpSLBuffer | 5.0 | SL追加バッファ（pips） |

### 出来高フィルター

| パラメーター | デフォルト | 説明 |
|------------|-----------|------|
| InpUseVolume | true | 出来高フィルター |
| InpVolPeriod | 20 | 平均計算期間 |
| InpVolMultiplier | 1.2 | 閾値（平均の1.2倍以上） |

### トレーリングストップ

| パラメーター | デフォルト | 説明 |
|------------|-----------|------|
| InpUseTrailing | true | トレーリング使用 |
| InpTrailingStart | 20.0 | 開始利益（20pips = 0.20円） |
| InpTrailingStep | 10.0 | ステップ（10pips） |

## 推奨バックテスト設定

```
Symbol:    USDJPY
Timeframe: M15
Model:     Every tick based on real ticks（最高精度）
Spread:    1〜3（ブローカーの実スプレッドに合わせる）
期間:       最低2年以上
```
