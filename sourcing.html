API未設定

eBay想定売値は /api/ebay-price（Cloudflare Worker内のworker.js）経由でeBay Browse APIから自動取得できます。 developer.ebay.com でClient ID/Secretを取得し、CloudflareのWorker設定 → Settings → Variables and Secrets に EBAY_CLIENT_ID / EBAY_CLIENT_SECRET（Secret種別）を設定してデプロイすると有効になります。 未設定の間は下の「自動取得」ボタンがエラーを表示するので、その場合は手動で入力してください。 仕入れ値は複数の仕入れ先から自動取得できます：Amazonは /api/amazon-price 経由でKeepa API （keepa.comでKEEPA_API_KEYを取得）、 楽天市場は /api/rakuten-price 経由で楽天商品検索API （楽天ウェブサービスで発行される RAKUTEN_APP_ID＝アプリケーションID(UUID形式)とRAKUTEN_ACCESS_KEY＝アクセスキー(pk_〜)の 両方を設定。2026年の楽天API刷新後は登録した「アプリケーションURL」とOrigin/Refererの一致チェックもあるため、 登録URLが既定と異なる場合はRAKUTEN_ORIGINも設定してください）、 Yahoo!ショッピングは /api/yahoo-price 経由でYahoo!ショッピング商品検索API （Yahoo!デベロッパーネットワークでYAHOO_CLIENT_IDを無料取得）から取得します。 いずれもWorkerのSettings → Variables and Secrets（Secret種別）に設定してください。 ※ヤフオク（Yahoo!オークション）は2020年に一般開発者向けWeb APIが提供終了しているため対応していません。メルカリも公式APIが無いため非対応です。 手数料はeBayカテゴリ選択、送料は重量帯別テーブルからそれぞれ自動計算されます（どちらもライブAPIではなく、公開されている標準料率・料金表を組み込んだものです。実際の値は変わるため定期的な確認・編集を推奨します）。
